# GenAI Vision Bootcamp 👁️✨

Welcome to my repository for the **Generative AI & Computer Vision Bootcamp** at Hamrah Academy. This intensive 12-week program focuses on modern AI technologies, specifically in the visual domain, covering everything from core mathematics to advanced Generative AI and Multimodal models.

## 🚀 About This Repository

This repository contains all my codes, projects, and assignments from the bootcamp. It serves as a comprehensive showcase of my journey in mastering Computer Vision and Generative AI.

## 📚 Course Syllabus & Curriculum

The program consists of over 200 hours of specialized training. Here is the breakdown of my learning path:

- **🐍 Python Programming** (19 Hours)
  _From pixel processing to deep visual intelligence._
- **🎯 Supervised Machine Learning** (21 Hours)
  _Intelligent decision-making from labeled data._
- **🔍 Unsupervised Machine Learning** (19 Hours)
  _Uncovering hidden patterns in images using unlabeled data._
- **📐 Mathematics in Data Science & AI** (14 Hours)
  _The mathematical foundations of AI for image processing._
- **🧠 Deep Learning** (19 Hours)
  _Neural network architectures for advanced image analysis._
- **🎞️ Image & Video Processing** (23 Hours)
  _Advanced techniques in digital image engineering._
- **👁️‍🗨️ Computer Vision** (33 Hours)
  _Modern algorithms for object detection and scene analysis._
- **🎨 Generative AI in Computer Vision** (23 Hours)
  _Utilizing generative models (GANs, Diffusion, etc.) for visual content creation._
- **🔗 Multimodal AI** (14 Hours)
  _Practical applications of multimodal models in machine vision._
- **💬 Prompt Engineering** (16 Hours)
  _Designing Vision-Language models through professional prompting._
